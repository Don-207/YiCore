# Yi STM32F407

Reference MCU: STM32F407ZGT6, LQFP144, 1 MiB Flash and 192 KiB SRAM.

The board identity is reserved. It becomes buildable after the STM32F4 SoC
backend, DeviceTree description and `st-stm32f4.cmake` adapter are added.
Board-specific clocks and pin assignments must be confirmed against the PCB.
